# Economia e Mercado — 1º TANE — Extensão Ibiúna

Versão visual com identidade inspirada nas cores institucionais da Etec/CPS.

## Arquivos

- `index.html` — página principal da turma.
- `atividade-01.html` — interface da atividade.
- `prof-junior.png` — foto do professor.

## Upload para Google Drive

No arquivo `atividade-01.html`, inserir a URL publicada do Google Apps Script em:

```javascript
const UPLOAD_ENDPOINT = "";
```

## Publicação no GitHub Pages

1. Envie os três arquivos para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Selecione **Deploy from a branch**.
4. Escolha `main` e `/ (root)`.
5. Salve.

A URL principal da turma continuará a mesma mesmo quando novas atividades forem acrescentadas.
